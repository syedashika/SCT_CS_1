# Caesar Cipher Encryption Project

This Java project implements Caesar Cipher for encrypting and decrypting messages using character shifts.

## Features
- Encrypt and decrypt text
- Handles uppercase, lowercase, and symbols
- Simple UI (optional)

## Learning Outcomes
- Substitution cipher logic
- Modular arithmetic
- Basics of cryptography
